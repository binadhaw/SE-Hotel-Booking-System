Why Sri Lanka

Serendib, Ceylon, Lanka — one island, a thousand journeys

Ancient traders called it Serendib — the name that gave the English language the word “serendipity”. In a single week you can climb a fifth-century rock fortress, sip tea where it grows, track leopards at dawn and watch the sun sink into the Indian Ocean.
